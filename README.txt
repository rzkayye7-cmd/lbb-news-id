# MLBB News ID

Website berita MLBB sederhana, siap dipasang di GitHub Pages.

## Cara online gratis
1. Buat akun di GitHub.
2. Buat repository baru, misalnya `mlbb-news-id`.
3. Upload `index.html`, `artikel.html`, `style.css`, dan folder `images`.
4. Masuk ke Settings → Pages.
5. Pilih Deploy from a branch → branch `main` → folder `/ (root)` → Save.
6. Tunggu beberapa saat. GitHub akan memberikan alamat website.

## Foto pemain
Folder `images` disiapkan untuk foto pemain. Gunakan foto yang kamu punya izin/lisensinya. Setelah punya foto, simpan misalnya sebagai `images/timnas.jpg`, lalu ubah bagian placeholder pada HTML menjadi:
<img src="images/timnas.jpg" alt="Timnas MLBB Indonesia">

## Catatan
Artikel contoh perlu dicek kembali dengan sumber resmi sebelum dipublikasikan.
